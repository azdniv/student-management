# Student Management

Aplikasi sederhana untuk menampilkan data mahasiswa dengan ReactJS (Vite). Tidak memakai backend atau database, semua data berupa data dummy di dalam state.

## Fitur

- Tabel data mahasiswa (NIM, Nama, No. Hp, Email, Alamat, Program Studi, Tahun Masuk) dengan `useState` dan `.map()`
- Jam digital yang diperbarui tiap 1 detik dengan `useEffect`, `setInterval`, dan `clearInterval`
- Informasi jumlah mahasiswa
- Styling dengan Vanilla CSS

## Cara Menjalankan

```bash
npm install
npm run dev
```

Lalu buka http://localhost:5173

## Teknologi

- React 18
- Vite
- Vanilla CSS
